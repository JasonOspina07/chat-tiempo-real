# Chat en Tiempo Real

Aplicación de chat en tiempo real construida con Node.js, Express y Socket.io que permite comunicación instantánea entre múltiples usuarios.

## Tecnologías

- **Node.js** + **Express** — Servidor
- **Socket.io** — Comunicación en tiempo real con WebSockets
- **HTML/CSS/JS** — Interfaz de usuario

## Características

- Mensajes en tiempo real entre múltiples usuarios
- Nombres de usuario personalizados
- Mensajes propios diferenciados visualmente
- Indicador de estado de conexión
- Envío con Enter o botón

## Instalación

1. Clona el repositorio
\```bash
git clone https://github.com/JasonOspina07/chat-tiempo-real.git
cd chat-tiempo-real
\```

2. Instala las dependencias
\```bash
npm install
\```

3. Inicia el servidor
\```bash
npm run dev
\```

4. Abre el navegador en
\```
http://localhost:3001
\```

## Uso

1. Abre la app en tu navegador
2. Escribe tu nombre
3. Escribe un mensaje y presiona **Enviar** o **Enter**
4. Abre otra pestaña para ver los mensajes en tiempo real
